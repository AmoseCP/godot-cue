# 人工检查清单

UI 交互和音画同步没法自动化。每个里程碑走一遍这份清单,
把结果记进 `NOTES.md`。

自动化部分见:
- `tests/test_core.gd` —— PCM 解码、峰值、缓存、排序、吸附(69 条)
- `tests/test_runtime.gd` —— `Cue` / `CueClock` / `CueMouthShape`(45 条)
- `tests/test_import.gd` —— Rhubarb / TextGrid 解析(50 条)
- `tests/test_lanes.gd` —— 轨道泳道几何与折叠(32 条)
- `tests/test_export.gd` —— 振幅包络与剧本生成(63 条)
- `tests/edit_harness/` —— undo/redo、持久化、泳道、包络、剧本(97 条,需在编辑器里跑)
- `tests/toggle_harness/` —— 插件反复启停
- `tests/determinism.sh` —— 双次渲染逐帧哈希比对

一键跑全部机器可验的部分:`tests/run_all.sh`

## M0 骨架

- [ ] 在项目设置里启用 / 禁用插件各 3 次,输出面板无 error、无 warning
- [ ] 底部出现「Cue」标签页,点击可展开/收起
- [ ] 禁用插件后「Cue」标签页消失,自动加载列表里没有残留的 `Cue`

## M1 波形

- [ ] 拖一段真实配音 WAV(16-bit PCM)进项目,新建 CueSheet 指向它
- [ ] 点「分析波形」,进度条推进期间**编辑器不卡死**(还能拖动窗口)
- [ ] 波形形状与 Audacity 里看到的一致(静音段是平的,爆破音是尖的)
- [ ] 滚轮缩放:从整段 60 秒/屏 一路拉到 0.2 秒/屏,**全程不掉帧**
- [ ] 缩放时鼠标底下的那一点不跑位
- [ ] 中键拖动可以平移;底部滚动条跟着动
- [ ] 换一个音频文件后,Inspector 提示「音频已变,建议重新分析」
- [ ] 故意把音频的导入压缩模式设成 QOA,波形仍然正常(会走源文件路径)
- [ ] 把源 .wav 从项目里删掉、只留导入产物,点分析 → 弹出中文提示教你关压缩,**不崩溃**

## M2 传输控制 ⚠️ 必须人耳验证

**这是唯一无法自动化的核心验收项。**

- [ ] 空格键播放/暂停
- [ ] 播放时播放头平滑推进,视图自动跟随
- [ ] **音画同步**:找一段有明确爆破音(比如 "啪")的配音,
      反复播放,判断播放头压到波形尖峰的那一刻是否正好听到那一声。
      偏差应 < 1 帧(30fps 下 33ms)。
      - [ ] macOS
      - [ ] Windows
- [ ] 如果听感上画面**慢于**声音,去项目设置调
      `cue/playback/extra_latency_ms`(调大 → 画面提前)。
      记下你机器上的合适值。
      > macOS 实测 `AudioServer.get_output_latency()` 返回 0,
      > CoreAudio 的真实延迟没有被自动补偿,大概率需要手调。
- [ ] 暂停后再播放,**不跳位**(接着刚才的地方响)
- [ ] 播放中点击波形任意位置,立刻从那里继续播
- [ ] 点标尺拖动,播放头跟着走

## M3 标记编辑

- [ ] 拖动标记三角形可移动;按住 `Ctrl` 拖动时吸附到帧
- [ ] 勾上「帧吸附」后,加标记和点击定位都吸附到帧
- [ ] 选中标记按 `Delete` 删除
- [ ] **连续做 20 次混合编辑,`Ctrl+Z` 逐步全部撤销、`Ctrl+Y` 全部重做**

       确认编辑器主 undo 栈里的动作名是中文且可读)

- [ ] 再点一次展开,恢复原位
- [ ] 工具栏的折叠/展开按钮一次性作用于所有轨
- [ ] 点轨道头的名字,该轨高亮;此时按 `M` 加的标记落在这条轨上
- [ ] 在波形区(泳道下方)点击 → 移动播放头,**不会**误选标记
